# Metro Dash

Metro Dash is a mobile-friendly endless running game.

## Features
- Three running lanes
- Left and right movement
- Jump and slide controls
- Coins and score
- Obstacles
- Touchscreen swipe controls

## Files
- app.py: Main game code
- requirements.txt: Required Python package
- README.md: Project information

## Run the game

Install the package:

pip install -r requirements.txt

Start the app:

streamlit run app.py

## Deploy online

1. Upload all three files to GitHub.
2. Open Streamlit Community Cloud.
3. Connect your GitHub account.
4. Select your repository.
5. Select app.py.
6. Click Deploy.

This is an original game inspired by endless-runner games.
It is not the official Subway Surfers game.
